# Gesture2Text

## Project Overview
Gesture2Text is a Deep Learning based ASL (American Sign Language) word recognition system that aims to recognize dynamic hand gestures from video input and convert them into text.

## Objective
- Recognize ASL signs using deep learning techniques.
- Convert sign gestures into understandable text output.
- Build a foundation for future sentence-level sign language translation.

## Technologies Used
- Python
- Deep Learning
- TensorFlow / PyTorch
- OpenCV
- MediaPipe

## Project Structure
- dataset/ → Dataset files
- notebooks/ → Experiment notebooks
- src/ → Source code
- models/ → Trained models
- results/ → Output and evaluation results
